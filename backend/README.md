# Backend

NestJS API и Telegram-бот (grammY) для VPN Bot. Описание проекта, архитектура и запуск — в [README в корне репозитория](../README.md).

```bash
npm ci
npm run migration:run   # применить миграции
npm run start:dev       # запуск в режиме разработки
npm run build           # сборка в dist/
```
